# @thing/sdlc-dual_engine_harness

coupled dual-engine autonomous software development lifecycle (sdlc) harness integrating deterministic statechart macro governance with agentic ai workflow micro execution.

## architecture summary

- **tier 1 (macro governance)**: deterministic, mathematically verifiable statechart engine (`xstate v5`) enforcing sequential lifecycle phases, transition invariants, and strict quality review gates.
- **tier 2 (micro execution)**: agentic ai workflow engine (`mastra v1`) orchestrating modular, single-responsibility workflows for autonomous code synthesis, test authoring, evaluation rubrics, and tool execution.
